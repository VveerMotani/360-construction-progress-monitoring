# The isolated build environment for DART (.tools/dart-venv). Python 3.12.
#
# Why its own venv, and not the API's: DART pins numpy<2 and was written
# against Meta's own SAM 3 checkpoint loader, both of which the API neither
# needs nor wants. Only two things cross from here into the main venv --
# the tensorrt runtime (same pin, below) and the files under data/dart/.
# See the README (TensorRT section).
#
# torch is installed separately by build_dart_engines.ps1 from the cu126
# index (torch==2.7.1, torchvision==0.22.1): DART was tested on 2.7 and its
# encoder-decoder export relies on the TorchScript ONNX exporter, which
# stopped being the default in torch 2.9.
#
# TensorRT wheels for 10.x are served from https://pypi.nvidia.com, not PyPI.
# The version here is THE pin: an engine only loads in the TensorRT version
# that built it, so the main venv carries exactly the same one.
